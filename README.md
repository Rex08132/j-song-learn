# 🎵 J-Song Learn - 日文歌曲互動學習室

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Rex08132/j-song-learn)

互動式日文歌曲學習工具，串接 YouTube 播放器與 Google Gemini AI 導師，支援歌詞同步滾動、點擊跳轉播放、一鍵詢問 AI 文法發音，以及生詞筆記本收藏。

## 功能特色
- 🎧 **YouTube 歌曲連動**：輸入歌名或貼上 YouTube 連結即刻播放。
- 📜 **LRC 同步高亮**：歌詞隨音樂自動滾動高亮，點選任意歌詞行直接跳轉進度。
- 🤖 **Gemini AI 日語導師**：點擊歌詞旁的「詢問 AI」，自動帶入上下文進行動詞變化、語法拆解與意境解析。
- 📚 **生詞本與筆記**：收藏重點解析，支援匯出 Anki 單字卡 (CSV)。

## 雲端一鍵部署
